Opção recomendada — webhook permanente
Configure uma vez no Kuku para que cada email novo seja entregue automaticamente ao servidor. Depois disso, os clientes só usam o campo de consulta normal.
Webhook URL
Abrir m.kuku.lu
  1. Entre na conta do Kuku usada pelo InstAddr.
  2. Abra as configurações de encaminhamento/webhook.
  3. Cole a URL acima.
  4. Envie um email de teste e depois atualize o status desta página.
Plano B — sincronização privada do navegador
Use apenas você, no seu navegador/admin. Isso não aparece mais para o cliente na home do InstAddr.
  1. Arraste o botão Favorito de sincronização para a barra de favoritos.
  2. Abra a inbox no m.kuku.lu.
  3. Clique no favorito para enviar sessão + emails recentes ao servidor.
  4. Volte ao InstAddr público e teste a consulta.
